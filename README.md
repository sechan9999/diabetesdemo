# Diabetes Drug Trial: Three Methods, With and Without Confounding

*[English README](README.en.md)*

같은 질문("26주차 HbA1c에 신약이 얼마나 효과가 있었나")에 세 가지 방법으로 답해보는
데모입니다. 단순 회귀, 준실험 설계인 RDD, 반복측정 혼합효과모형을 차례로 적용합니다.

결론은 두 가지입니다. 미관측 교란이 없으면 방법을 복잡하게 만들어도 추정치가 더 정확해지지
않습니다. 미관측 교란이 있으면 단순 회귀는 편향되고, 준실험 설계가 표본을 줄이는 비용을
정당화합니다. 방법의 복잡도가 아니라 식별 가정이 성립하는지가 갈림길입니다.

## 배경

LLM 에이전트에게 분석을 맡기면 준실험 설계나 복잡한 통계모형을 기본값처럼 제안하는 경향이
있습니다. 이 데모는 그 경향이 실제로 얼마나 필요한지를 시뮬레이션으로 점검합니다. 참값을 미리
고정해 두었으므로, 각 방법이 그 값을 얼마나 잘 회복하는지를 직접 대조할 수 있습니다.

## 데이터

실제 임상시험 데이터가 아니라 시뮬레이션입니다. 기저 HbA1c가 7.0% 이상인 환자에게만 신약이
처방된다고 가정하고(현실의 처방 임계값 상황을 흉내), 실제 처치효과를 -1.2%p로 고정해 두고
세 방법이 이 값을 얼마나 잘 회복하는지 비교합니다.

## 세 가지 방법

1. **단순 회귀 (ANCOVA)** — 26주차 HbA1c를 기저치로 보정한 OLS 회귀
2. **준실험 설계 (RDD)** — 처방 기준선(7.0%) 근처 표본만 써서 국소선형회귀
3. **복잡한 통계모형 (혼합효과모형)** — 0·12·26주 반복측정 전체를 환자별 임의절편으로 모형화
   - 3a. 시간을 선형(`treated * week`)으로 둔 설정
   - 3b. 시간을 범주형(`treated * C(week)`)으로 둔 MMRM 설정. 실제 임상시험의 표준.

## 실행

```bash
pip install -r requirements.txt
python analysis.py              # 교란이 없는 경우: 세 방법 비교
python analysis_confounded.py   # 미관측 교란이 있는 경우: 결론이 뒤집힌다
```

## 결과 요약

### 교란이 없을 때 (`analysis.py`)

| 방법 | 처치효과 추정치 | 표본 |
|---|---|---|
| 단순 회귀 | -1.264 | 2,000 |
| RDD | -1.385 | 658 |
| 혼합효과모형 (선형 시간) | -1.295 | 2,000 |
| 혼합효과모형 (범주형, MMRM) | -1.243 | 2,000 |
| (실제 설정값) | -1.2 | — |

네 방법 모두 참값 근처로 수렴하고, 95% 신뢰구간도 모두 참값을 포함합니다. 준실험 설계는
표본을 3분의 1로 줄이는 대가를 치릅니다. "26주차에 효과가 있었나"라는 질문 하나에는
단순 회귀로 충분했습니다.

혼합효과모형이 단순 회귀보다 참값에서 멀었던 것은 복잡해서가 아니라 **시간 설정이 틀렸기
때문**입니다. 시뮬레이션의 실제 감쇠는 0주 0.000 / 12주 0.600 / 26주 1.000인데, 시간을
선형으로 두면 12주에 0.462를 가정하게 됩니다. 범주형(MMRM)으로 고치면 -1.243으로
가까워집니다. 복잡도 자체가 아니라 설정의 정확도가 문제였습니다.

### 교란이 있을 때 (`analysis_confounded.py`)

위 결론에는 큰 단서가 붙습니다. `analysis.py`의 세계에는 **미관측 교란이 없습니다.** 처방이
관측된 기저 HbA1c만의 결정함수이고 결과모형도 정확히 설정되어 있으니, 단순 회귀가 참값을
맞히는 것은 발견이 아니라 설계상 당연한 귀결입니다.

`analysis_confounded.py`는 그 가정을 깹니다. 의사가 차트에 기록되지 않는 중증도(U)를 보고도
처방한다고 두면 — 즉 처방을 퍼지(fuzzy)하게 만들면:

| 방법 | 처치효과 추정치 | 편향 | 표본 |
|---|---|---|---|
| 단순 회귀 (U 미관측) | -0.864 | +0.336 | 8,000 |
| 오라클 회귀 (U 관측) | -1.215 | -0.015 | 8,000 |
| 퍼지 RDD | -1.224 | -0.024 | 2,934 |
| (실제 설정값) | -1.2 | — | — |

단순 회귀는 약효를 **28% 축소 보고**합니다. U를 넣은 오라클 회귀가 참값을 회복하므로 편향의
원인이 모형이 아니라 미관측 교란임이 확인됩니다. 퍼지 RDD는 기준선에서의 점프만 쓰기 때문에
U에 영향받지 않고 참값을 회복합니다 (부트스트랩 95% CI [-1.384, -1.060], B=1000).

### 그래서

준실험 설계는 공짜가 아니지만(표본 8,000 → 2,934), **교란이 있을 때는 그 값을 합니다.**
"단순한 방법으로 충분한가"는 방법의 복잡도가 아니라 **식별 가정이 성립하는지**에 달려 있습니다.

## 유의사항

- 모든 데이터는 `numpy` 시드 42로 생성한 가상 데이터입니다. 실제 제약회사나 실제 약물의
  임상시험 결과가 아닙니다.
- `analysis_confounded.py`의 퍼지 RDD는 Wald 비율(축약형 점프 / 1단계 점프)로 LATE를
  추정합니다. 이 추정량의 표준오차는 OLS에서 바로 나오지 않으므로 부트스트랩으로 구했습니다.
  대역폭 민감도(±0.25 ~ ±1.0)는 스크립트 4번 절에 출력됩니다.
- 재현성을 위해 시드를 고정했으므로 재실행해도 같은 숫자가 나옵니다.
